# TokoKita Kasir

Website Kasir Toko berbasis PHP dan MySQL.

## Deskripsi
TokoKita adalah aplikasi kasir sederhana yang digunakan untuk mengelola data barang, melakukan transaksi penjualan, dan melihat riwayat penjualan.

## Teknologi yang Digunakan
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Fitur
- Register
- Login
- Dashboard
- Tambah barang
- Edit barang
- Hapus barang
- Upload foto barang
- Transaksi penjualan
- Perhitungan total otomatis
- Perhitungan kembalian otomatis
- Riwayat penjualan
- Logout
- Responsive desktop dan mobile
- Data barang dan transaksi terpisah untuk setiap akun user

## Database
Database yang digunakan adalah MySQL.

File database:
`database.sql`

Tabel yang digunakan:
- users
- barang
- penjualan
- penjualan_detail

## Cara Menjalankan
1. Install XAMPP.
2. Jalankan Apache dan MySQL.
3. Simpan folder project ke dalam folder `htdocs`.
4. Buka phpMyAdmin.
5. Buat database dengan nama `kasir_toko`.
6. Import file `database.sql`.
7. Buka browser.
8. Jalankan:
   `http://localhost/kasir_toko/`
